## Risk register

| Risk | Mitigation |
|---|---|
| Scanner false-positives on test fixtures | Default-skip `*.test.*` / `*.spec.*` / `tests/` / `fixtures/` directories |
| Schema/example drift | ajv test pinned in CI |
| Action bundle staleness | CI `git diff --quiet actions/check/dist` step fails if uncommitted |
| Secret leakage via MCP | Names-as-sensitive default redaction; default-deny on mutating tools; never returns values |
